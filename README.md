# Vue 3 + Vite

## Windows offline edition

Run `npm.cmd run build:offline` to build the Windows installer and portable package. The offline edition bundles PHP/MySQL, supports local account setup and single-PC billing, and includes daily backups, USB export and validated restore. See [desktop/README.md](desktop/README.md) for installation, recovery and verification. Run `npm.cmd run test:offline` to exercise an isolated local billing and backup/restore flow.

See [PROJECT_GUIDE.md](PROJECT_GUIDE.md) for the application architecture and initial source review.

This template should help get you started developing with Vue 3 in Vite. The template uses Vue 3 `<script setup>` SFCs, check out the [script setup docs](https://v3.vuejs.org/api/sfc-script-setup.html#sfc-script-setup) to learn more.

Learn more about IDE Support for Vue in the [Vue Docs Scaling up Guide](https://vuejs.org/guide/scaling-up/tooling.html#ide-support).
